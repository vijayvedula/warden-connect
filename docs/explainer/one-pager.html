warden-connect · one page · for architecture, technology and security leadership

AI agents are already calling production services. Nothing records it, scopes it, or switches it off.

One control closes that gap: a signed, expiring contract for every agent-to-service relationship — enforced in the request path, and revocable across the whole estate in under a minute with proof it landed.

Why existing controls do not cover this

1

Identity and gateways answer a different question. IAM authenticates the caller; gateways shape the call. Neither answers may this agent talk to this service at all, and on which tools?

2

Today the answer is a ticket. Two-to-three weeks, an unclear approver, a shared credential from a wiki — and nothing enforced at the end of it. So engineers route around it.

3

So there is no register. No inventory, no owners, no expiry, no scoping — and in an incident, no way to answer "what can this agent reach?"

The control, in one picture

Adoption — five steps, each independently valuable

1

Fingerprint the tool surface

Hash exactly what was contracted. A silently changed tool description — where injection payloads live — moves the hash and names the tool.

cost: one command
2

Build the register

Agents and services with named owners, in a tamper-evident log. The inventory the estate does not have.

cost: a pipeline step
3

Make approval an artifact

Signed, expiring, machine-checkable. Low-risk requests auto-approve in seconds. The approval is the enforcement.

cost: an issuer key
4

Enforce in the path

Agents see only contracted tools; uncontracted calls are refused before the service is reached. Starts in observe mode.

cost: a sidecar
5

Estate-wide, plus a kill switch

Distribution with acknowledgement, and containment as one dual-controlled command with per-node proof.

cost: a service to operate

Each step pays for itself on its own. You can stop on any of them indefinitely — steps 1 and 2 need no infrastructure, no budget line and no approval, so one team can prove the model in a week.

What it means in your terms

Group Chief Architect

A boundary that composes

  • Integrates through two signed artifacts and one identifier — not a shared library, cluster or release train.
  • Format, canonicalisation and checks are specified, with published conformance tests.
  • No lock-in to our data plane: implement the checks in your own egress layer and still interoperate.

AI / Agent Architect

A smaller, explicit surface

  • Agents receive a narrower tool list, so the wrong tool cannot be called by accident.
  • Tool descriptions are hashed — a silently altered description is detected rather than trusted.
  • Works for agent-to-agent and cross-organisation on the same artifact; neither side exposes a catalogue.

CTO

Delivery gets faster

  • Low-risk access moves from weeks to seconds via policy auto-approval.
  • Application teams change no manifests and no configuration — the platform ships it in the base image.
  • The friction budget is net negative by design. That is the adoption bet, and it is deliberate.

CIO

Operable, and honest when degraded

  • Runs as a sidecar, a shared gateway, or inside an egress proxy you already run.
  • Pull with acknowledgement: a missed update shows up as measurable lag, never as silence.
  • Poor connectivity degrades to signed offline bundles rather than to a control that stops working quietly.

CISO

Blast radius, and a kill switch

  • "What can this agent reach?" becomes one query instead of an archaeology exercise.
  • Containment is one dual-controlled command with per-node confirmation — nodes that cannot confirm are reported unconfirmed and fail closed, never assumed successful.
  • Tamper-evident evidence answers "what was permitted on the 14th" to the minute.

What it deliberately does not do

It does not replace identity, authorisation or network controls. It adds the relationship boundary those layers do not cover, and it cannot widen them.

Deployed in visibility-only mode it enforces nothing — and says so, loudly, rather than reporting a green status.

That last point is the design principle: a control that reports success while doing nothing is worse than no control, because nobody investigates something that looks fine.

The decision in front of you is small. Steps 1 and 2 require no infrastructure, no budget and no mandate — one team, one week, and the estate gets a register with owners that can prove it was not edited afterwards.
